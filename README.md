# 俄罗斯方块 · Tetris

一个纯 HTML/CSS/JavaScript 实现的俄罗斯方块游戏，零依赖，单文件即可运行。

## 在线试玩

开启 GitHub Pages 后访问仓库页面即可直接游玩。

## 本地运行

直接用浏览器打开 `index.html` 即可，无需安装任何依赖。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| ← / → | 左右移动 |
| ↓ | 软降 |
| ↑ / X | 顺时针旋转 |
| Z | 逆时针旋转 |
| 空格 | 硬降 |
| C | 暂存方块 |
| P | 暂停 |
| R | 重新开始 |

## 特性

- 标准 10×20 棋盘，7 种经典方块
- 7-bag 随机算法（消除连续同款）
- 简易墙踢（Wall Kick）
- 幽灵方块预览落点
- 下一块 / 暂存预览
- 分数、等级、消行统计，随等级加速
- 键盘 + 屏幕按钮双操作
